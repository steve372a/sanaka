# Checklist

## Product

- [ ] `Media/` 正式作为机器包可移除介质目录保留。
- [ ] `Disks/` 继续作为唯一正式受管虚拟硬盘目录。
- [ ] ISO 和软盘等可移除介质进入 `Media/`。
- [ ] 虚拟硬盘进入 `Disks/`。
- [ ] `.img` 根据挂载用途归类，不只按扩展名判断。
- [ ] 机器包根目录不作为用户上传区域。
- [ ] 桌面端外部资源能力保持不变。
- [ ] 网页端外部资源可见但不可修改。

## Web Sandbox

- [ ] 网页端只暴露“安装介质”和“虚拟磁盘”两个入口。
- [ ] “安装介质”映射到 `Media/`。
- [ ] “虚拟磁盘”映射到 `Disks/`。
- [ ] 网页文件接口不能列出机器包根目录。
- [ ] 网页文件接口不能读取 `machine.svm` 或 `preview.png`。
- [ ] 上传目标由资源用途决定，不接受任意相对路径。
- [ ] 上传只允许单层安全文件名。
- [ ] 上传使用排他创建，不覆盖已有文件。
- [ ] 路径穿越、绝对路径、盘符路径和符号链接逃逸被拒绝。
- [ ] 网页响应和错误不泄露宿主路径。

## Runtime And Export

- [ ] Runtime 正确解析 `Disks/...` 虚拟硬盘路径。
- [ ] Runtime 正确解析 `Media/...` 可移除介质路径。
- [ ] Runtime 不把相对路径解释为进程工作目录。
- [ ] 历史相对路径保持兼容读取。
- [ ] 导出磁盘进入 `Disks/`。
- [ ] 导出 ISO 和软盘进入 `Media/`。
- [ ] 不含介质的导出包不创建空 `Media/`。
- [ ] 导出配置写入最终的机器包相对路径。
- [ ] 网页导出不能包含外部宿主资源。

## UI

- [ ] 文件管理器显示“安装介质”和“虚拟磁盘”。
- [ ] 上传完成后只刷新资源列表，不自动挂载或修改配置。
- [ ] 外部资源按钮触发原因提示，不显示内部“只读”标签。
- [ ] 界面不显示 `.saka`、`machine.svm`、bundle root 或宿主路径。

## Verification

- [ ] 上传 ISO 后文件真实位于 `Media/`。
- [ ] 上传虚拟硬盘后文件真实位于 `Disks/`。
- [ ] 分别以硬盘和软盘用途上传 `.img`，目标目录正确。
- [ ] 网页无法访问机器包根目录和内部文件。
- [ ] 导出包含 ISO 时路径和配置正确。
- [ ] 不含介质的导出不会产生空 `Media/`。
- [ ] 路径与软链接安全测试通过。
- [ ] `npm run typecheck`。
- [ ] `npm test -- --run`。
- [ ] `npm run build`。

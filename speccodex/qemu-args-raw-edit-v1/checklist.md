# Checklist

## Product Direction

- [ ] 高级参数区的主心智明确为“原样命令编辑器”
- [ ] 不再把高级参数区作为全量智能解析器继续扩展
- [ ] 保留少量高价值 UI 同步，不追求任意参数自动反推

## Editing Model

- [ ] 内建参数行支持按整行原样编辑
- [ ] 编辑时不过度预检测、不过度语法校验
- [ ] 语法错误由 QEMU 启动时报错
- [ ] UI 已知字段仍可承接部分编辑结果
- [ ] `-m/-smp/-name` 这类简单直填参数编辑后不进入“自定义”
- [ ] UI 未知值可进入“自定义”态

## Removal Model

- [ ] 只有 custom 行和可关闭内建行出现垃圾桶
- [ ] 不可关闭内建行没有垃圾桶
- [ ] 删除可关闭内建行后回写 `none` / `disabled`
- [ ] 删除后完整命令列表刷新不报配置缺失

## Runtime

- [ ] 完整命令展示和实际启动尽量使用同一套生成语义
- [ ] `gpu = none` 等关闭态不会让命令构建崩溃
- [ ] 不新增复杂高级参数预检测器

## UI

- [ ] `none` 显示为字面量 `none`
- [ ] UI 能显示“自定义”态
- [ ] 删除按钮位置清晰且不误导

## Verification

- [ ] 相关 `typecheck` 通过
- [ ] Runtime 相关测试通过
- [ ] 高级参数列表相关测试通过
- [ ] 至少验证一组“合法 raw edit”
- [ ] 至少验证一组“非法 raw edit 由 QEMU 报错”

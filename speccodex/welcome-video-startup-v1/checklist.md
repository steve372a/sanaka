# Checklist

- [ ] 新增 `showWelcomeOnStartup` 设置，默认值为 `true`。
- [ ] 缺少新字段的旧设置解析后仍显示欢迎窗口。
- [ ] 桌面版初始化完成后显示欢迎窗口。
- [ ] 网页版入口加载后显示欢迎窗口。
- [ ] 欢迎窗口标题为“欢迎使用 Sanaka”。
- [ ] 右上角有圆形叉号按钮，并且有可访问名称。
- [ ] 当前版本视频按 `video/<version>.mp4` 命名。
- [ ] 开发环境直接读取根目录下的当前版本视频。
- [ ] 本地视频缺失时从同版本 Sanaka GitHub Release 自动下载。
- [ ] `0.0.4-beta` 使用 Release 标签 `v0.0.4(beta)` 和资源名 `0.0.4-beta.mp4`。
- [ ] 下载地址为 `https://github.com/steve372a/sanaka/releases/download/v0.0.4(beta)/0.0.4-beta.mp4`。
- [ ] 下载使用临时文件，完成后再原子改名。
- [ ] 开发环境下载失败时可以使用黑色占位继续启动。
- [ ] 正式构建默认把当前版本视频复制到应用资源目录的 `video` 目录。
- [ ] 安装包默认自带当前版本视频，安装后可以直接播放。
- [ ] 删除安装包内置视频后不会尝试写回应用安装目录。
- [ ] 内置视频缺失时从 GitHub Release 下载到用户数据目录缓存。
- [ ] 发布构建下载失败或缺少当前版本视频时明确失败。
- [ ] 视频缺失或解码失败时回退为纯黑色背景。
- [ ] 中间视频区域保持 16:9，四角为圆角，窄屏没有溢出或变形。
- [ ] 视频自动播放、无限循环并强制静音。
- [ ] 不显示进度条或任何原生视频控件。
- [ ] `video/*.mp4` 不进入 Git 历史。
- [ ] Release 先上传视频，再构建和上传各平台安装包。
- [ ] 底部有“不再提醒”和“关闭”两个按钮。
- [ ] 点击“关闭”只关闭当前窗口。
- [ ] 点击圆叉号只关闭当前窗口。
- [ ] 按 `Escape` 只关闭当前窗口。
- [ ] 点击“不再提醒”后保存 `showWelcomeOnStartup: false` 并关闭窗口。
- [ ] 保存失败时不把永久关闭状态误报为成功。
- [ ] 欢迎窗口不会等待 QEMU 检测或其他后台任务。
- [ ] 减弱动态效果开启后仅保留淡入淡出。
- [ ] 网页版只能读取明确暴露的当前版本视频资源，不能访问任意宿主机文件。
- [ ] 相关组件测试覆盖首次显示、临时关闭、永久关闭、旧设置默认值和 16:9 布局。
